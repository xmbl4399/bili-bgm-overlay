> **⚠️ 依赖说明**：Bangumi 的 API 没有 CORS 头，**必须**跑在 Tampermonkey / Violentmonkey 这类支持 `GM_xmlhttpRequest` 的环境里。装在"无 GM 权限"的环境会显示「加载失败」，这是环境限制而非脚本问题。

打开 `www.bilibili.com/anime/*`，把 B站 那套番剧区**整页换成自制的 Bangumi 番剧浏览页**。数据全部来自 [Bangumi](https://bgm.tv)，只保留最上面那排 B站 顶栏（也能一键连顶栏一起藏掉）。

## 为什么做这个

B站 番剧区按"季度"编排、评分只有 B站 自己那套；Bangumi 的评分体系更细、条目更全（含 OVA / 剧场版 / 冷门旧番），但它的浏览页是给网页端用力的，手机和 TV 上不好看。

这个脚本把两者的长处拼起来：**用 Bangumi 的数据，套一个为窄屏和遥控器准备好的界面，扒在 B站 的地址上**。

## 它长什么样

```
● Bangumi   TV  WEB  OVA  剧场版  日剧  欧美剧  华语剧  韩剧  电影      ◐  ⚙
─────────────────────────────────────────────────────────────────────────
 2026  2025  2024  2023  2022 … 2006
─────────────────────────────────────────────────────────────────────────
 9月 · 6 部
 ┌──────┐ ┌──────┐ ┌──────┐
 │ 封面 │ │ 封面 │ │ 封面 │   ← 右上角评分徽章，左上角流派 tag，左下角集数
 └──────┘ └──────┘ └──────┘
 8月 · 2 部 …
```

| 区域 | 说明 |
|---|---|
| **B站 顶栏** | 默认**原封不动保留**（首页/番剧/直播/搜索框/头像/消息…全都能点），内容区排在它下面 |
| **九分类 tab** | `TV / WEB / OVA / 剧场版 / 日剧 / 欧美剧 / 华语剧 / 韩剧 / 电影`，胶囊选中，窄屏可左右拖拽滑动 |
| **年份栏** | `2026 → 2006` 共 21 个 chip，横向可拖 |
| **月份分组** | 倒序排列，空月自动隐藏，逐月懒加载 |
| **卡片** | 封面 3:4；评分徽章（**≥7 分金色**）；流派 tag（最多 2 个）；集数（仅 TV）；点击跳 B站搜索，右键复制标题 |

## 特色

- **评分用 Bangumi 的**，不是 B站 的 —— 同一部番两边的分数差得挺多，这里给的是 Bangumi 口径。
- **流派标签是数据驱动的白名单**：从四年真实 tag 里收敛出的两级词表（27 个题材 + 12 个来源/受众），不是手写死的词。覆盖率见下方。
- **主题跟随 B站 自己的深/浅色开关**（不是跟随系统）。B站 切深色，这页跟着切。
- **720P 与手机都做了适配**：9 个分类在 1280×720 下**绝不换行**，尺寸随视口用 `clamp()` 连续收缩；窄屏隐藏品牌文字只留圆点；两栏都能**按住左右拖**（鼠标 / 触控笔 / 手指都行）。
- **请求极少**：走 `api.bgm.tv/v0`，该接口**列表项自带全量用户投票 tag**，所以**不需要逐条拉详情** —— TV 全年只要 **4 个请求**（对比老方案 14 请求 + 33% 详情补拉）。
- **在 B站 头像弹层里放了一条状态行**，显示当前通路/缓存/白名单规模，方便自查。

## 关于「韩剧」这个 tab

**Bangumi 没有韩剧分类。** `platform=电视剧` 是个混合容器，没有 `韩国` 这样的独立平台值。

所以这个 tab 是 **`platform=电视剧` AND tag 命中 `韩剧/韩国/韩语`** 的近似实现，实测：

| 年份 | 命中率 |
|---|---|
| 2026 | 14/14 = **100%** |
| 2025 | 68/78 = **87%** |

漏掉的基本是 tag 池本身为空的条目（Bangumi 上没人给它们投中文 tag），**没有"韩国生产却被漏掉"的情况**。另外已核实 `platform=电视剧` 里**没有美剧混入**（美剧有自己的 platform）。

> 该 tab 依赖 v0 通路（p1 的列表项拿不到用户投票 tag）。如果你手动把数据源切成"仅 p1"，韩剧命中会明显减少。

## 数据来源与请求量

| 项 | 值 |
|---|---|
| 主数据源 | `api.bgm.tv/v0/subjects`（列表项自带全量 tags，无需补拉） |
| 兜底 | `next.bgm.tv/p1`（仅 v0 失败时） |
| 缓存 | 当年 12 小时，历史年份 30 天 |
| 依赖 | 无（不引任何第三方库） |

## 已知限制

- **只替换 `/anime/*`**，B站 番剧以外的区域不受影响。
- **不登录 Bangumi**，用的是公开接口；因此**看不到 Bangumi 的收藏状态**。
- 部分条目**两边的 tag 字段都是空的**（约 1.7%，多为欧美网络动画 / 短片），这类卡片就是没有流派标签，不是 bug。
- **「电影」与「韩剧」是前端过滤实现**：电影要拉全平台再筛 `platform=电影`（因为 `cat≥4` 会 400）；韩剧要靠 tag，成色见上。

## 兼容性

在 **Microsoft Edge（无头 CDP）** 上做过完整端到端回归：9 个分类四档视口（1280×720 / 1366×768 / 1024×768 / 800×600）全部单行不换行，浮层、主题切换、设置面板、懒加载、图片加载均通过；**脚本自身未捕获异常 0 条**。

需要 **Tampermonkey（或 Violentmonkey 等兼容管理器）**。已在 Chromium 系浏览器验证。
